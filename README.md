# White Alpaca

The website of White Alpaca, an independent studio of one, and of **The Iceberg**: a quiet place for unfinished music. It doesn't just catch your song ideas, it brings your old ones back, so nothing is lost.

Live at **https://whitealpaca.tech**

Plain HTML, CSS and a little JavaScript. No build step, no trackers, no cookies, no third-party requests.
