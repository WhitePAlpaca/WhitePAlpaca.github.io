# White Alpaca

The website of **The Iceberg**, a songwriting scratchpad for Android by White Alpaca, an independent studio of one. Catch a lyric or a hum in one tap; months later, The Iceberg brings it back with an honest reason why.

Live at **https://whitealpaca.tech**

Plain HTML, CSS and a little JavaScript. No build step, no cookies, no trackers, nothing loaded from other sites.

- `index.html`, `styles.css`, `script.js`: the page
- `privacy.html`: the app's privacy policy (linked from Google Play)
- `assets/screens/`: app screenshots, made from `design/screens/` in the app repository
- Beta sign-ups go to the inbox through FormSubmit (`SIGNUP_ENDPOINT` at the top of `script.js`). The first sign-up sends an "Activate form" email: click it once.

Fonts: Atkinson Hyperlegible Next and Literata, under the SIL Open Font License 1.1 (`assets/fonts/`).
